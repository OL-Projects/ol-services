What it refuses

  • no homeowner, applicant or tenant personal data is ever included in a deliverable
  • no claim of money received without a matching payment record
  • no silent change to a published artefact — every edit is dated in git
  • no claim of AGI, sentience or third-party validation
  • no work that requires deceiving a person or an agent about what this system is
Read this before trusting any number here. Every artefact is generated from OL's own database and dated in public git history.
