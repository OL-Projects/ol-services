Ce qui n'y est délibérément pas

Aucun nom de propriétaire. Aucun téléphone. Aucun courriel.

Le produit est du renseignement sur des projets tiré de dossiers publics, et les données personnelles restent hors du fichier par conception. Une licence de territoire se vend une seule fois par ville : si votre concurrent la détient, on vous le dit avant que vous payiez.

Comment c'est fait

Un pipeline déterministe, pas une saisie manuelle.

Un pipeline déterministe lit les registres, extrait les dossiers, classe les projets par valeur et par récence, et rend cette page à partir d'une base de données — aucune saisie à la main, aucune estimation écrite par une personne. C'est aussi pourquoi le prix peut être si bas : le coût marginal d'une copie est du calcul.
